Student Academic Performance Prediction System

An intelligent Machine Learning web application designed for educational institutions to accurately forecast final examination scores, identify at-risk students early, and provide personalized academic intervention recommendations.

Access Portal Student Sign Up
Prediction Factors
  • Attendance percentage & attendance cliff warning
  • Previous semester examination marks
  • Continuous internal assessment scores
  • Daily study hours & time management
  • Assignment completion & submission score
  • Total class absences impact penalty
Student Module

Register, log in, maintain your profile, input academic metrics, instantly preview predicted marks, expected grade category, and receive actionable tips to improve.

Admin Module

Secure dashboard to oversee all registered students, monitor class distribution, inspect global prediction logs, and identify vulnerable students needing tutoring.

Scikit-Learn ML Engine

Trained on multi-factor academic datasets with 80/20 train-test splitting. Evaluated using MAE, MSE, RMSE, and R² determination coefficient.
